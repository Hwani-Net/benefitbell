## 2. 차별화 우월 기능 (북극성 정합 5종)

혜택알리미만 충족하는 핵심 가치:

1. **3초 결과** — 프로필 입력 → 즉시 매칭 % + 추천 상위 10개 (경쟁사 모두 "검색"만 가능)
2. **자격 판정** — % 배지 + 3줄 요약 + 무관 항목 0점 필터 (경쟁사 0)
3. **원스톱 신청** — 서류 체크리스트 → 정부24 발급 URL 직접 연결 (할루시 0%, 화이트리스트)
4. **광고 0** — Anti-Scope 정책: 대출/카드/보험 광고 영구 차단 (캐시노트가 망한 이유)
5. **알림 비-스팸** — 같은 혜택 같은 날 1회만, 시스템 재발송 금지 (능동 리마인더만)

## 4. 시장 포지셔닝 결론

- **혜택알리미는 "AI 자격 판정 + 원스톱 신청 안내" 카테고리에서 단독 1위**. 5종 18개 기능 매트릭스에서 충족률 100% (2위 국민비서 31% 대비 3배+ 격차).
- **차별화 핵심**: AI 판정 % 배지 + 무관 혜택 0점 필터 + 원스톱 정부24 링크 화이트리스트 — 이 조합은 어떤 경쟁사도 충족하지 못함.
- **약점**: 데이터 커버리지(지자체)와 시니어 UX(큰 글자). 두 영역 모두 P1으로 분류, 다음 사이클 우선 처리.
